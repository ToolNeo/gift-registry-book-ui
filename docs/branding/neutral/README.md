# 在线礼簿 · 晴光蓝白标准视觉

与 Ant Design 中后台（`#1677FF`）完全统一的通用蓝白视觉：清透极简的蓝白柔光抽象全屏背景、纯白悬浮卡片与明净钴蓝徽章标志。适用于婚丧嫁娶、寿宴乔迁等全场景入口，登录后无缝衔接管理端。

| 文件 | 规格 | 用途 |
| --- | --- | --- |
| `logo.svg` / `logo.png` | 1024 × 1024，圆角徽章外透明 | 系统标志；SVG 可编辑 |
| `login-background.jpg` / `login-background.png` | 16:9 宽屏 | 全屏登录背景；支持系统设置直接上传 |

默认登录页内置 `login.jpg` 与 `logo.svg`。PNG / JPG 均小于 4 MiB，可在「系统设置」中直接上传替换；背景采用 `cover` 居中裁切，中央与四角保持柔和留白，确保桌面端与手机端的标题、表单及页脚备案信息清晰可读。

主色：Ant Design 蓝 `#1677FF`（悬停 `#4096FF`、按压 `#0958D9`）、深岩蓝字色 `#0F172A`、次级文字 `#526277`、纯白卡片 `#FFFFFF`、浅蓝白底色 `#F4F7FC`。

本目录不覆盖上一级原有品牌素材。
